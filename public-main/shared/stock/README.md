# مكتبة الصور الجاهزة (Stock)

الصور اللي هنا بتتنشر مع الموقع الأساسي (`www`) على `https://www.discover-sharm.com/stock/…`، والأدمن والمالك بيختاروا منها من زرار **"مكتبة الصور الجاهزة"** في محرر الفنادق والرحلات والانتقالات والمطاعم والوجهات والمدونة (وزرار **"من المكتبة"** لصورة الغرفة). الاختيار من المكتبة مفيهوش رفع ولا commit ولا build — وبيرفعوا صورة جديدة بس لو اللي محتاجينه مش موجود.

## الهيكل
```
shared/stock/
  general/                 صور تنفع لكل الأقسام (بحر، غروب، شعاب…)
  hotels/   [album/]       الفنادق (pools/ rooms/ beach/ …)
  excursions/ [album/]     الرحلات (diving/ snorkeling/ desert/ …)
  transfers/  restaurants/  destinations/  journal/
```
- كل قسم يقدر يكون فيه **ألبومات** (مجلد فرعي واحد) بتظهر كأزرار فلترة في النافذة.
- أسماء الملفات والمجلدات: حروف إنجليزي وأرقام و`-` `_` `.` بس (بدون مسافات أو عربي)، والامتدادات `jpg` `png` `webp`.
- الحجم: يفضل **أقل من 450 KB** للصورة (البيلد بيحذّر لو أكبر). الأبعاد المناسبة حوالي 1600×1067.
- كل قسم يقدر يكون فيه `meta.json` لعناوين عربي/إنجليزي وكلمات بحث (اختياري):
```json
{
  "pool-sunset.jpg":          { "ar": "حمام سباحة وقت الغروب", "en": "Pool at sunset", "tags": ["غروب", "حمام سباحة"] },
  "diving/ras-mohamed.jpg":   { "ar": "شعاب راس محمد",          "en": "Ras Mohamed reef" }
}
```
من غير `meta.json` البحث بيشتغل على اسم الملف واسم الألبوم (`ras-mohamed-reef.jpg` → "Ras Mohamed Reef").

## الإضافة
حط الصور في المجلد المناسب → commit → الموقع الأساسي يتبني وينشر (`node tools/build.mjs`) → تظهر في النافذة. الحد الأقصى للموقع على الخطة المجانية 20,000 ملف.
