# 2026-10-29 — Cache Rule + auto version for the media domain · new splash screen

## 1) Cache Rule for `/catalog/*` and `/settings/*` on `media.discover-sharm.com`
Cloudflare does not cache `.json` by default, so these files need a Cache Rule. To make the CDN copy refresh itself when the files change, the Workers now publish a **version number** (content hash) next to each file:

- `catalog/version.json` → `{"v":"<hash>"}` (written by the content Worker, AFTER `catalog/bundle.json`)
- `settings/version.json` → `{"v":"<hash>"}` (written by the settings Worker, AFTER `settings/settings.json`)
- The sites read the pointer (a few bytes, rechecked every ~5 s) and then request `bundle.json?v=<hash>` / `settings.json?v=<hash>` (`mediaUrl()` in `shared/supabase-api.js`). Changed content = new hash = new URL = the CDN fetches it fresh. Nothing is ever purged. If the pointer is missing the plain URL is used (old behaviour).
- The hash only changes when the content changes (unchanged cron runs write nothing).

### Create the rules (once) — Cloudflare → `discover-sharm.com` zone → Caching → Cache Rules
**Rule 1 — "media json versioned"** (cached for a year; safe because the URL changes with the content)
- Expression (Edit expression):
  `(http.host eq "media.discover-sharm.com" and (starts_with(http.request.uri.path, "/catalog/") or starts_with(http.request.uri.path, "/settings/")) and http.request.uri.path ne "/catalog/version.json" and http.request.uri.path ne "/settings/version.json" and http.request.uri.query contains "v=")`
- Cache eligibility: **Eligible for cache** · Edge TTL: **Ignore cache-control header and use this TTL → 1 year** · Browser TTL: **Override origin → 1 year**

**Rule 2 — "media json pointers / unversioned"** (short, follows the file's own `max-age=5`)
- Expression: `(http.host eq "media.discover-sharm.com" and (starts_with(http.request.uri.path, "/catalog/") or starts_with(http.request.uri.path, "/settings/")) and not http.request.uri.query contains "v=")`
- Cache eligibility: **Eligible for cache** · Edge TTL: **Use cache-control header if present, bypass cache if not** · Browser TTL: **Respect origin TTL**

Do NOT give `version.json` a long TTL — it is the one file that must stay fresh (the expressions above already keep it in Rule 2).
Images (`/img/*`) are not covered: they already cache for a year (`immutable`) and Cloudflare caches image files by default.

### Check
`curl -sI "https://media.discover-sharm.com/catalog/bundle.json?v=<hash from version.json>"` twice → the second shows `cf-cache-status: HIT`.
After the next save in the admin (or the 5-minute cron) `version.json` shows a new `v` and the sites pick it up within seconds.
Deploy order: deploy both Workers first (they create the pointers), then the sites.
